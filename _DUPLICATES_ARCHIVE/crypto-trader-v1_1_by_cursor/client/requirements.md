## Packages
framer-motion | Smooth animations for the dashboard
recharts | Visualization for PNL and trade data
date-fns | Date formatting for timestamps
clsx | Utility for constructing className strings conditionally
tailwind-merge | Utility for merging Tailwind classes efficiently

## Notes
The dashboard needs a "cyberpunk/neon" aesthetic.
We will use a dark theme by default with vibrant accents.
Real-time data fetching will be simulated with `refetchInterval` in React Query for this MVP since no WebSocket is explicitly set up in the provided schema, but the UI should look "live".
