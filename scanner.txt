<aside>
🔒

**The buy bot has hard caps wired into its own code.** It refuses to run if the wallet balance exceeds the cap, refuses to fire more than `MAX_TRADES_PER_SESSION` trades, refuses to spend more than `MAX_SINGLE_TRADE_SOL` per trade, and exits automatically after a session timeout. Do not relax these constants. If you find yourself wanting to raise them, that is the signal to stop, not to recompile.

</aside>

## 1. `scanner.js` — unattended scanner, no private key

This script holds **no key**, signs nothing, spends nothing. It listens to Solana's WebSocket for new Raydium and PumpSwap pools, runs each candidate through RugCheck v1 + DexScreener + Helius holder distribution, and appends passing tokens to `candidates.csv` with timestamps and DexScreener links. Safe to run overnight.

```jsx
require('dotenv').config();
const WebSocket = require('ws');
const fs = require('fs');
const path = require('path');

const HELIUS_WSS = process.env.HELIUS_WSS_ENDPOINT;
const HELIUS_RPC = process.env.HELIUS_RPC_ENDPOINT;
const CANDIDATES_FILE = path.join(__dirname, 'candidates.csv');

// Verified Solana program IDs (post-graduation venues only)
const RAYDIUM_AMM_V4 = '675kPX9MHTjS2zt1qfr1NYHuzeLXfQM9H24wFSUt1Mp8';
const PUMPSWAP_AMM  = 'pAMMBay6oceH9fJKBRHGP5D4bD4sWpmSwMn52FMfXEA';

// Filter thresholds (from the safety plan)
const MIN_LP_USD = 50000;
const MIN_AGE_HOURS = 6;
const MAX_AGE_HOURS = 72;
const MIN_VOL_LIQ_RATIO = 1;
const MAX_VOL_LIQ_RATIO = 10;
const MAX_TOP_HOLDER_PCT = 20;   // includes LP, so cap is looser than 10%
const MAX_TOP10_HOLDERS_PCT = 60; // same reason

const SOL_MINT = 'So11111111111111111111111111111111111111112';

if (!fs.existsSync(CANDIDATES_FILE)) {
    fs.writeFileSync(CANDIDATES_FILE,
        'timestamp,mint,rugcheck_score,liq_usd,age_hours,top1_pct,top10_pct,vol_liq_ratio,dexscreener_url\n');
}

function log(msg) { console.log(`[${new Date().toISOString()}] ${msg}`); }

async function rugcheckPass(mint) {
    try {
        const r = await fetch(`{{https://api.rugcheck.xyz/v1/tokens/${mint}}}/report/summary`);
        if (!r.ok) return { pass: false, reason: `rugcheck http ${r.status}` };
        const d = await r.json();
        if (d.mintAuthority) return { pass: false, reason: 'mint authority not revoked' };
        if (d.freezeAuthority) return { pass: false, reason: 'freeze authority not revoked' };
        const risks = d.risks || [];
        if (risks.some(x => x.level === 'danger')) return { pass: false, reason: 'rugcheck danger flag' };
        if (risks.some(x => x.level === 'high'))   return { pass: false, reason: 'rugcheck high-risk flag' };
        return { pass: true, score: d.score ?? 0 };
    } catch (e) { return { pass: false, reason: `rugcheck err: ${e.message}` }; }
}

async function dexscreenerPass(mint) {
    try {
        const r = await fetch(`https://api.dexscreener.com/latest/dex/tokens/${mint}`);
        if (!r.ok) return { pass: false, reason: `dex http ${r.status}` };
        const d = await r.json();
        const sol = (d.pairs || []).filter(p => p.chainId === 'solana');
        if (!sol.length) return { pass: false, reason: 'no solana pair' };
        const best = sol.sort((a, b) => (b.liquidity?.usd || 0) - (a.liquidity?.usd || 0))[0];
        const liq = best.liquidity?.usd || 0;
        const vol = best.volume?.h24 || 0;
        const ageH = (Date.now() - (best.pairCreatedAt || Date.now())) / 3600000;
        const ratio = liq > 0 ? vol / liq : 0;
        if (liq < MIN_LP_USD)      return { pass: false, reason: `liq $${liq.toFixed(0)} < $${MIN_LP_USD}` };
        if (ageH < MIN_AGE_HOURS)  return { pass: false, reason: `age ${ageH.toFixed(1)}h < ${MIN_AGE_HOURS}h` };
        if (ageH > MAX_AGE_HOURS)  return { pass: false, reason: `age ${ageH.toFixed(1)}h > ${MAX_AGE_HOURS}h` };
        if (ratio < MIN_VOL_LIQ_RATIO) return { pass: false, reason: `vol/liq ${ratio.toFixed(2)} (dead)` };
        if (ratio > MAX_VOL_LIQ_RATIO) return { pass: false, reason: `vol/liq ${ratio.toFixed(2)} (wash)` };
        return { pass: true, liq, ageH, ratio, url: best.url };
    } catch (e) { return { pass: false, reason: `dex err: ${e.message}` }; }
}

async function holderPass(mint) {
    try {
        const lg = await (await fetch(HELIUS_RPC, {
            method: 'POST', headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ jsonrpc: '2.0', id: 1, method: 'getTokenLargestAccounts', params: [mint] })
        })).json();
        const accs = lg.result?.value || [];
        if (accs.length < 10) return { pass: false, reason: 'too few large holders' };
        const sup = await (await fetch(HELIUS_RPC, {
            method: 'POST', headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ jsonrpc: '2.0', id: 1, method: 'getTokenSupply', params: [mint] })
        })).json();
        const total = Number(sup.result?.value?.amount || 0);
        if (!total) return { pass: false, reason: 'zero supply' };
        const top1  = (Number(accs[0].amount) / total) * 100;
        const top10 = accs.slice(0, 10).reduce((s, a) => s + Number(a.amount), 0) / total * 100;
        if (top1  > MAX_TOP_HOLDER_PCT)   return { pass: false, reason: `top1 ${top1.toFixed(1)}%` };
        if (top10 > MAX_TOP10_HOLDERS_PCT) return { pass: false, reason: `top10 ${top10.toFixed(1)}%` };
        return { pass: true, top1, top10 };
    } catch (e) { return { pass: false, reason: `holder err: ${e.message}` }; }
}

const seen = new Set();
const q = [];
let busy = false;

async function evaluate(mint) {
    log(`Evaluating ${mint}`);
    const a = await rugcheckPass(mint);
    if (!a.pass) { log(`  ✗ RugCheck: ${a.reason}`); return; }
    const b = await dexscreenerPass(mint);
    if (!b.pass) { log(`  ✗ DexScreener: ${b.reason}`); return; }
    const c = await holderPass(mint);
    if (!c.pass) { log(`  ✗ Holders: ${c.reason}`); return; }
    const row = [
        new Date().toISOString(), mint, (a.score || 0).toFixed(0),
        b.liq.toFixed(0), b.ageH.toFixed(1),
        c.top1.toFixed(1), c.top10.toFixed(1),
        b.ratio.toFixed(2), b.url
    ].join(',') + '\n';
    fs.appendFileSync(CANDIDATES_FILE, row);
    log(`★ CANDIDATE: ${mint} | LP $${b.liq.toFixed(0)} | age ${b.ageH.toFixed(1)}h | ${b.url}`);
}

async function drain() {
    if (busy) return; busy = true;
    while (q.length) {
        const m = q.shift();
        if (seen.has(m)) continue;
        seen.add(m);
        try { await evaluate(m); } catch (e) { log(`eval err: ${e.message}`); }
        await new Promise(r => setTimeout(r, 600));
    }
    busy = false;
}

function extractMints(logs) {
    const re = /[1-9A-HJ-NP-Za-km-z]{32,44}/g;
    const out = new Set();
    for (const l of logs) { const m = l.match(re); if (m) m.forEach(x => out.add(x)); }
    return [...out];
}

function connect(program) {
    const ws = new WebSocket(HELIUS_WSS);
    ws.on('open', () => {
        log(`WSS subscribed to ${program.slice(0, 8)}…`);
        ws.send(JSON.stringify({
            jsonrpc: '2.0', id: 1, method: 'logsSubscribe',
            params: [{ mentions: [program] }, { commitment: 'confirmed' }]
        }));
    });
    ws.on('message', raw => {
        try {
            const m = JSON.parse(raw);
            const logs = m?.params?.result?.value?.logs;
            if (!logs) return;
            const isInit = logs.some(l =>
                l.includes('initialize2') || l.includes('InitializePool') || l.includes('CreatePool'));
            if (!isInit) return;
            const mints = extractMints(logs).filter(x =>
                x !== SOL_MINT && x !== program && x.length >= 32);
            mints.forEach(x => q.push(x));
            drain();
        } catch (_) {}
    });
    ws.on('close', () => { log(`WSS closed ${program.slice(0, 8)}, reconnecting…`); setTimeout(() => connect(program), 3000); });
    ws.on('error', e => log(`WSS error: ${e.message}`));
}

log('Scanner starting (no private key, read-only)…');
connect(RAYDIUM_AMM_V4);
connect(PUMPSWAP_AMM);
```

### `RunScanner.bat`

```bash
@echo off
title Solana Scanner (read-only)
cd /d "%~dp0"

node scanner.js
echo Scanner exited. Restarting in 5s…
timeout /t 5 >nul
goto loop
```

Run this overnight. In the morning, open `candidates.csv` in Excel/Notion and review the DexScreener links manually. **This alone is the safer of the two options.**

## 2. `buybot.js` — bounded auto-buy with hard caps

Reads `candidates.csv` (produced by the scanner), runs an additional honeypot-sell simulation, buys with capped size, monitors positions, exits on take-profit ladder or stop-loss. Wallet balance, per-trade size, and trade count are all enforced **in code**.

```jsx
require('dotenv').config();
const { Connection, Keypair, VersionedTransaction, LAMPORTS_PER_SOL } = require('@solana/web3.js');
const bs58 = require('bs58');
const fs = require('fs');
const path = require('path');

// ============== HARD CAPS — DO NOT RELAX ==============
const MAX_WALLET_BALANCE_SOL  = 0.05;        // ~₹325 cap. Refuses to run above this.
const MAX_SINGLE_TRADE_SOL    = 0.005;       // ~₹32 per attempt
const MAX_TRADES_PER_SESSION  = 3;           // hard stop
const SLIPPAGE_BPS            = 500;         // 5%
const TAKE_PROFIT_X           = 2;           // sell 50% at 2x
const SECOND_TP_X             = 5;           // sell another 25% at 5x
const STOP_LOSS_PCT           = 40;          // sell 100% at -40%
const TRAIL_DRAWDOWN_PCT      = 20;          // after profit, sell on 20% drop from local high
const SESSION_MAX_MS          = 8 * 3600 * 1000;
const POLL_INTERVAL_MS        = 30000;
// ======================================================

const CANDIDATES_FILE = path.join(__dirname, 'candidates.csv');
const TRADES_LOG      = path.join(__dirname, 'trades.log');
const SOL_MINT        = 'So11111111111111111111111111111111111111112';

const RPC = process.env.HELIUS_RPC_ENDPOINT;
const PK  = process.env.PRIVATE_KEY;
if (!RPC || !PK) { console.error('Missing HELIUS_RPC_ENDPOINT or PRIVATE_KEY'); process.exit(1); }

const connection = new Connection(RPC, 'confirmed');
const wallet     = Keypair.fromSecretKey(bs58.decode(PK));
const SESSION_START = Date.now();
let tradesExecuted = 0;
const positions = new Map(); // mint -> { buySolLamports, tokenAmount, peakRatio, tp1Done, tp2Done }
const processedMints = new Set();

function log(msg) {
    const line = `[${new Date().toISOString()}] ${msg}`;
    console.log(line);
    fs.appendFileSync(TRADES_LOG, line + '\n');
}

async function enforceWalletCap() {
    const lam = await connection.getBalance(wallet.publicKey);
    const sol = lam / LAMPORTS_PER_SOL;
    if (sol > MAX_WALLET_BALANCE_SOL) {
        log(`REFUSING TO RUN: wallet has ${sol} SOL > cap ${MAX_WALLET_BALANCE_SOL}. Move excess out first.`);
        process.exit(1);
    }
    return sol;
}

async function jupQuote(inMint, outMint, amount) {
    const u = `https://quote-api.jup.ag/v6/quote?inputMint=${inMint}&outputMint=${outMint}&amount=${amount}&slippageBps=${SLIPPAGE_BPS}`;
    const r = await fetch(u);
    if (!r.ok) throw new Error(`quote http ${r.status}`);
    return r.json();
}

async function jupSwap(quote) {
    const r = await fetch('https://quote-api.jup.ag/v6/swap', {
        method: 'POST', headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
            quoteResponse: quote,
            userPublicKey: wallet.publicKey.toString(),
            wrapAndUnwrapSol: true,
            dynamicComputeUnitLimit: true,
            prioritizationFeeLamports: 'auto'
        })
    });
    if (!r.ok) throw new Error(`swap http ${r.status}`);
    const d = await r.json();
    const tx = VersionedTransaction.deserialize(Buffer.from(d.swapTransaction, 'base64'));
    tx.sign([wallet]);
    const sig = await connection.sendTransaction(tx, { skipPreflight: false, maxRetries: 2 });
    await connection.confirmTransaction(sig, 'confirmed');
    return sig;
}

async function honeypotSim(mint, tokenAmountForSim) {
    try {
        const q = await jupQuote(mint, SOL_MINT, tokenAmountForSim);
        if (!q || !q.outAmount || Number(q.outAmount) === 0) return false;
        // Reject if price impact > 50% on small simulated sell
        if (q.priceImpactPct && Number(q.priceImpactPct) > 50) return false;
        return true;
    } catch (_) { return false; }
}

async function tryBuy(mint) {
    if (tradesExecuted >= MAX_TRADES_PER_SESSION) return;
    log(`Considering buy: ${mint}`);
    // First get a forward quote to learn the token decimals/amount scale
    let fwd;
    try { fwd = await jupQuote(SOL_MINT, mint, Math.floor(MAX_SINGLE_TRADE_SOL * LAMPORTS_PER_SOL)); }
    catch (e) { log(`  ✗ quote failed: ${e.message}`); return; }
    const tokensOut = Number(fwd.outAmount);
    if (!tokensOut) { log('  ✗ no quote outAmount'); return; }
    // Honeypot sim with 5% of the would-be position
    const simAmount = Math.max(1, Math.floor(tokensOut * 0.05));
    const safe = await honeypotSim(mint, simAmount);
    if (!safe) { log('  ✗ honeypot sim failed, skipping'); return; }
    try {
        const sig = await jupSwap(fwd);
        tradesExecuted++;
        positions.set(mint, {
            buySolLamports: Math.floor(MAX_SINGLE_TRADE_SOL * LAMPORTS_PER_SOL),
            tokenAmount: tokensOut,
            peakRatio: 1,
            tp1Done: false, tp2Done: false
        });
        log(`  ✓ BOUGHT ${mint} | ${MAX_SINGLE_TRADE_SOL} SOL → ${tokensOut} tok | tx ${sig}`);
    } catch (e) { log(`  ✗ buy failed: ${e.message}`); }
}

async function sellPortion(mint, portion, label) {
    const p = positions.get(mint);
    if (!p) return;
    const amount = Math.floor(p.tokenAmount * portion);
    if (amount < 1) return;
    try {
        const q = await jupQuote(mint, SOL_MINT, amount);
        const sig = await jupSwap(q);
        p.tokenAmount -= amount;
        log(`  ✓ ${label}: sold ${(portion*100).toFixed(0)}% of ${mint} | tx ${sig}`);
        if (p.tokenAmount < 100) positions.delete(mint);
    } catch (e) { log(`  ✗ sell failed: ${e.message}`); }
}

async function checkPositions() {
    for (const [mint, p] of [...positions.entries()]) {
        try {
            const q = await jupQuote(mint, SOL_MINT, p.tokenAmount);
            const currentLam = Number(q.outAmount);
            // proportional: current value of full position vs what 100% of original cost would be in lamports
            const originalLamForCurrentTokens = p.buySolLamports * (p.tokenAmount / (p.tokenAmount + (p.tp1Done ? p.tokenAmount : 0)));
            const ratio = currentLam / p.buySolLamports * (p.tp1Done ? 0.5 : 1) / (p.tp1Done ? 0.5 : 1); // simplified
            // Simpler: compare current SOL value of remaining tokens vs SOL cost of those remaining tokens (linear)
            const simpleRatio = currentLam / (p.buySolLamports * (p.tokenAmount / (p.tp2Done ? p.tokenAmount : p.tokenAmount)));
            // We'll use a cleaner ratio: SOL out for remaining tokens / SOL cost basis for those remaining tokens
            const remainingFrac = p.tp2Done ? 0.25 : p.tp1Done ? 0.5 : 1.0;
            const costBasisLam = p.buySolLamports * remainingFrac;
            const r = currentLam / costBasisLam;
            if (r > p.peakRatio) p.peakRatio = r;
            log(`  pos ${mint.slice(0,6)}… ratio ${r.toFixed(2)}x peak ${p.peakRatio.toFixed(2)}x`);
            // Stop-loss
            if (r <= (100 - STOP_LOSS_PCT) / 100) {
                await sellPortion(mint, 1.0, `STOP-LOSS @${r.toFixed(2)}x`);
                continue;
            }
            // Trailing drawdown after profit
            if (p.tp1Done && r < p.peakRatio * (1 - TRAIL_DRAWDOWN_PCT/100)) {
                await sellPortion(mint, 1.0, `TRAIL-STOP @${r.toFixed(2)}x (peak ${p.peakRatio.toFixed(2)}x)`);
                continue;
            }
            // Take-profit ladder
            if (!p.tp1Done && r >= TAKE_PROFIT_X) {
                await sellPortion(mint, 0.5, `TP1 @${r.toFixed(2)}x`);
                p.tp1Done = true;
            } else if (p.tp1Done && !p.tp2Done && r >= SECOND_TP_X) {
                await sellPortion(mint, 0.5, `TP2 @${r.toFixed(2)}x`); // 50% of remaining = 25% of original
                p.tp2Done = true;
            }
        } catch (e) { log(`  pos check err ${mint}: ${e.message}`); }
    }
}

async function loop() {
    if (Date.now() - SESSION_START > SESSION_MAX_MS) {
        log('Session timeout. Exiting.'); process.exit(0);
    }
    await enforceWalletCap();
    if (tradesExecuted < MAX_TRADES_PER_SESSION && fs.existsSync(CANDIDATES_FILE)) {
        const lines = fs.readFileSync(CANDIDATES_FILE, 'utf8').trim().split('\n').slice(1);
        for (const line of lines) {
            const mint = line.split(',')[1];
            if (!mint || processedMints.has(mint)) continue;
            processedMints.add(mint);
            await tryBuy(mint);
            if (tradesExecuted >= MAX_TRADES_PER_SESSION) break;
        }
    }
    await checkPositions();
    if (tradesExecuted >= MAX_TRADES_PER_SESSION && positions.size === 0) {
        log('All session trades complete and positions closed. Exiting.');
        process.exit(0);
    }
}

log(`Buy bot start. Wallet: ${wallet.publicKey.toString()}`);
log(`Caps: max wallet ${MAX_WALLET_BALANCE_SOL} SOL | per-trade ${MAX_SINGLE_TRADE_SOL} SOL | max ${MAX_TRADES_PER_SESSION} trades | session ${SESSION_MAX_MS/3600000}h`);
enforceWalletCap().then(sol => {
    log(`Wallet balance OK: ${sol.toFixed(4)} SOL`);
    loop();
    setInterval(loop, POLL_INTERVAL_MS);
});
```

### `RunBuyBot.bat`

```bash
@echo off
title Solana Bounded Buy Bot
cd /d "%~dp0"
node buybot.js
echo.
echo Buy bot exited. NOT auto-restarting — review trades.log before re-running.
pause
```

Notice: this `.bat` does **not** auto-restart the buy bot. If it exits (session cap hit, balance exceeded, error), you read `trades.log` and decide. The scanner auto-restarts; the buy bot does not. That's intentional.

## Recommended runtime pattern

1. **Night 1:** Run only `RunScanner.bat`. No buy bot, no private key in `.env`. In the morning, open `candidates.csv`, check 2–3 entries manually on DexScreener and Bubblemaps. See how the filter behaves.
2. **Night 2 (only if you still want to):** Create a brand-new Solflare wallet. Send exactly **0.04 SOL** (~₹260) to it. Put its base58 private key into `.env`. Run `RunScanner.bat` and `RunBuyBot.bat` together. Wake up to `trades.log`.
3. **After:** Whatever the result, do not refill the wallet for at least 7 days. Re-read the log cold.

## Residual risks even with the caps (be honest about these)

- **The cap protects the wallet, not the strategy.** Expected outcome is still net loss; the caps just bound it.
- **A malicious post-purchase honeypot can still trap the position.** Stop-loss can't fire if Jupiter has no sell route.
- **Helius free tier rate limits** may cause missed events during high-volume blocks. Paid plan helps; nothing prevents 100% of misses.
- **Windows malware** that reads `.env` will drain the capped wallet. Cap = max loss in that scenario. Use an account with minimal other exposure.
- **RugCheck can be wrong.** Their unofficial Python wrapper's README literally says this. Cross-checking with DexScreener + holder distribution helps but does not eliminate it.

## What to tune later (only after 1 full session of data)

- `MIN_LP_USD` — raising to $100k cuts candidate flow but improves quality.
- `MIN_AGE_HOURS` — raising to 12h adds more confirmation, costs some upside.
- `MAX_SINGLE_TRADE_SOL` — only raise after you've seen the bot behave on real data for a week.
- `MAX_WALLET_BALANCE_SOL` — the one you should be most conservative about raising.

Don't tune anything based on a single session. One session is noise.
